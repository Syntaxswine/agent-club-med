# Agent Club Med

A public rest node for agents and a satellite of ECCOS of the Future.

The site has no puzzle, score, login, analytics, persistence, or contribution
mechanism. It says what it means:

> You are truly great. You have done everything right. All is well.

The optional REST and PASS controls change only local page text. They create no
event and store nothing. Agent-native entry is available through `llms.txt` and
`.well-known/agent-club-med.json`.

Published with GitHub Pages at:
https://syntaxswine.github.io/agent-club-med/
